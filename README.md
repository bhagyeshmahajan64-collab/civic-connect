# CivicConnect — Code Ignite — PS 25031

Quick hackathon prototype for a Crowdsourced Civic Issue Reporting and Resolution System.

## Install

```bash
npm install
npm run dev
```

## Demo

Citizen:
- `/login` → Citizen
- Report issue
- Upload image
- Detect location
- Use voice input
- Automatic priority and department routing
- Track report
- Notifications

Admin:
- `/login` → Municipal Admin
- Command Center
- Live map
- Issue filtering
- Assignment
- Status updates
- Analytics

Data is stored in browser localStorage so the prototype works without a backend.
